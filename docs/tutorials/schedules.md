## A schedule is data
A schedule is an ordered list of stages. Each entry names an **operator** (a registered stage), its **params**
(each a Param, see {doc}`../getting-started/concepts`), and optionally `repeat` and `when`.

```python
from neurogenesis.stages.base import run_schedule

project = {
    "version": "1.0.0", "fields": {}, "plugins": [],
    "schedule": [
        {"name": "seed",   "operator": "seed_cells",  "params": {"N": 20, "jitter": 5.0}},
        {"name": "divide", "operator": "proliferate", "params": {"prob": 0.5, "jitter": 1.0}, "repeat": 3},
        {"name": "death",  "operator": "apoptosis",
         "params": {"prob": {"type": "Gene", "path": ["death", "p"], "lo": 0.0, "hi": 0.5}}},
    ],
}
genome = {"death": {"p": 0.2}}

checkpoints = run_schedule(project, genome, seed=0, checkpoints=True)
print([int(t.alive.sum()) for t in checkpoints])
```
```text
[20, 29, 43, 65, 56]
```
- `seed_cells` places 20 cells; `proliferate` runs three times (each cell divides with probability 0.5);
  `apoptosis` removes cells with a probability read from the genome — an evolvable gene.
- `checkpoints=True` returns the tissue after every stage repetition, for previews and analysis.
- Each repetition has its own random stream derived from `(seed, stage name, repetition)`: inserting a stage does not
  change what the others draw.

## Genes of a schedule
```python
from neurogenesis.params import collect_genes
print(collect_genes(project["schedule"]))      # [(path, low, high, integer), ...] — ready for evolution
```

## Cost of a schedule
```python
from neurogenesis.stages.base import schedule_cost
print(schedule_cost(project, N=10_000, E=1_000_000))    # (bytes, operations), declared by each stage
```

## Available stages

| Operator | Task | What it does |
|---|---|---|
| `seed_cells` | C1 | create cells at a point, in a geometry, with a region and type |
| `proliferate` | C2 | cell division with a probability; daughters inherit lineage |
| `apoptosis` | C3 | cell death: by probability, density, or missing inputs / outputs |
| `migrate` | C4 | move cells (direction, radial, towards a target; stop field, boundary) |
| `sort` | C5 | reorder cells along an axis by a key |
| `express` | C6 | gene-regulatory step on expression channels (morphogens, neighbours) |
| `differentiate` | C7 | assign cell types and neuron parameters from conditions |
| `grow_axons` | C8 | connections by axon guidance |
| `place_by_hand`, `connect_by_hand` | C9 | explicit cell positions and synapses (supervised) |
| `prune`, `scale`, `myelinate` | C10, C12 | remove weak synapses, scale weights, shorten delays |
| `refine_by_activity` | C11 | simulate inside development and apply a plasticity rule |
| `legacy_grow_stage` | A5 | the original `grow` procedure as one stage |

Every stage's parameters can be listed through the bridge (`stages` method) or in the {doc}`../reference/api`.

## Legacy plans as schedules
Any `BodyPlan` can be compiled into a Project whose schedule reproduces `grow()` bit for bit:
```python
from neurogenesis.development.legacy_compiler import compile_plan_to_project
project = compile_plan_to_project(plan)
tissue = run_schedule(project, genome, seed=0, legacy_stream=True)
net = tissue.to_network()
```
`legacy_stream=True` exists only for legacy plans (one random stream shared by all stages, as in `grow`); new
schedules never use it.
