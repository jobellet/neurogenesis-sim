## A schedule is data
A schedule is an ordered list of stages. Each entry names an **operator** (a registered stage), its **params**
(each a Param, see {doc}`../getting-started/concepts`), and optionally `repeat` and `when`.

```python
from neurogenesis.stages.base import run_schedule

project = {
    "version": "1.0.0", "fields": {}, "plugins": [],
    "schedule": [
        {"name": "seed",   "operator": "seed_cells",  "params": {"N": 20, "jitter": 5.0}},
        {"name": "divide", "operator": "proliferate", "params": {"prob": 0.5, "jitter": 1.0}, "repeat": 3},
        {"name": "death",  "operator": "apoptosis",
         "params": {"prob": {"type": "Gene", "path": ["death", "p"], "lo": 0.0, "hi": 0.5}}},
    ],
}
genome = {"death": {"p": 0.2}}

checkpoints = run_schedule(project, genome, seed=0, checkpoints=True)
print([int(t.alive.sum()) for t in checkpoints])
```
```text
[20, 29, 43, 65, 56]
```
- `seed_cells` places 20 cells; `proliferate` runs three times (each cell divides with probability 0.5);
  `apoptosis` removes cells with a probability read from the genome — an evolvable gene.
- `checkpoints=True` returns the tissue after every stage repetition, for previews and analysis.
- Each repetition has its own random stream derived from `(seed, stage name, repetition)`: inserting a stage does not
  change what the others draw.

## A complete pipeline from JSON
Two regions seeded in boxes, divisions, a gene-regulatory step driven by a gradient, fates from the gradient,
axons whose tuning width is a gene, myelination, activity-dependent refinement and pruning:

```python
import json
import numpy as np
from neurogenesis.stages.base import run_schedule
from neurogenesis.spiking.batch import simulate_counts

gene = lambda path, lo, hi: {"type": "Gene", "path": path, "lo": lo, "hi": hi}
project = {
    "version": "1.0.0", "plugins": [],
    "fields": {"tissue": {"type": "Box", "center": [0, 0, 0], "size": [40, 40, 10]},
               "target": {"type": "Box", "center": [60, 0, 0], "size": [40, 40, 10]},
               "grad": {"type": "AnalyticField", "expr": "x / 40 + 0.5"}},
    "schedule": [
        {"name": "seed", "operator": "seed_cells", "params": {"N": 30, "geometry": "tissue", "region": 0}},
        {"name": "seed2", "operator": "seed_cells", "params": {"N": 30, "geometry": "target", "region": 1}},
        {"name": "divide", "operator": "proliferate", "params": {"prob": 0.5, "jitter": 1.0}, "repeat": 2},
        {"name": "express", "operator": "express",
         "params": {"K": 1, "morphogens": [{"field": {"type": "Field", "name": "grad"}, "weights": [1.0]}]}},
        {"name": "fate", "operator": "differentiate", "params": {"types": [
            {"type_id": 1, "condition": "field_grad < 0.5", "sign": 1},
            {"type_id": 2, "condition": "field_grad >= 0.5", "sign": -1}]}},
        {"name": "axons", "operator": "grow_axons", "params": {
            "projections": [[0, 1]],
            "guidance": {"0->1": {"B": [[1, 0, 0], [0, 1, 0], [0, 0, 0]], "c": [0, 0, 0],
                                  "sigma": gene(["g", "sigma"], 0.05, 0.5), "p0": 0.8, "w": 300}},
            "conduction_velocity": 2.0}},
        {"name": "myelin", "operator": "myelinate", "params": {"factor": 0.5}},
        {"name": "refine", "operator": "refine_by_activity", "params": {"ticks": 100}},
        {"name": "prune", "operator": "prune", "params": {"threshold": 1}},
    ]}
project = json.loads(json.dumps(project))          # a project is plain JSON
tissue = run_schedule(project, genome={"g": {"sigma": 0.2}}, seed=0)
net = tissue.to_network()
ext = np.zeros((1, net.num_neurons), np.int32); ext[0, :5] = 100
for model in ("lif_int", "two_compartment", "hh"):
    print(model, int(simulate_counts([net], [ext], ticks=100, model=model)[0].sum()))
```
```text
lif_int 203
two_compartment 205
hh 27
```
The network has 131 cells and 319 synapses (166 inhibitory, from the type-2 cells), with delays of 10–22 ticks
after myelination. In this run `refine_by_activity` has no `rule`, so it leaves the weights unchanged.

## Available stages

| Category | Operators | What they do |
|---|---|---|
| Population (C1–C3, C14) | `seed_cells`, `proliferate`, `apoptosis`, `cell_cycle_clock`, `tissue_expand` (C24) | create cells, divide with lineage, prune by density or inputs, track mitotic cycles, dilate tissue with growth |
| Migration & sorting (C4–C5) | `migrate`, `sort`, `mosaic` | radial/tangential/chemotactic migration with stop fields, axis sorting & differential adhesion, homotypic exclusion |
| Expression & fate (C6–C7, C15) | `express`, `temporal_competence`, `differentiate` | gene-regulatory network step with morphogens and neighbours, competence cascade, conditional cell-type assignment |
| Connectivity (C8–C9, C16–C19, C25) | `grow_axons`, `fasciculate`, `choice_point`, `cluster_boutons`, `partner_select`, `bilinear_select`, `place_by_hand`, `connect_by_hand` | chemoaffinity guidance, bundling & midline switching, multiplicity, compatibility matrices, low-rank bilinear selection, explicit placement & wiring |
| Arbors & dendrites (N1–N3, N5) | `grow_arbors`, `arbor_synapses`, `dendritic_attenuate` | branching neurite trees, proximity-based Peters'-rule synapses with path delays, passive dendritic attenuation |
| Pharmacology & modulation (P1–P5, C21) | `set_transmitters`, `express_receptors`, `assign_receptors`, `pharmacology`, `apply_drug`, `transporter_switch`, `neuromodulate` | transmitter bitmasks, receptor profiles & context compilation, drug dosing, NKCC1→KCC2 chloride shift, volume-transmitted three-factor modulation |
| Maturation & freeze (C10–C13, C22–C23, A5) | `prune`, `scale`, `myelinate`, `refine_by_activity`, `competitive_elimination`, `critical_period_gate`, `freeze`, `legacy_grow_stage` | weight/coactivity pruning, homeostatic scaling, myelination, STDP/Hebbian/three-factor activity refinement, competitive synapse loss, plasticity gating, network export |

Every stage's parameters, defaults and limits: {doc}`../reference/stages` (also via `python -m neurogenesis ui-schema` or the bridge `stages` method).

## Legacy plans as schedules
Any `BodyPlan` can be compiled into a Project whose schedule reproduces `grow()` bit for bit:
```python
from neurogenesis.development.legacy_compiler import compile_plan_to_project
project = compile_plan_to_project(plan)
tissue = run_schedule(project, genome, seed=0, legacy_stream=True)
net = tissue.to_network()
```
`legacy_stream=True` exists only for legacy plans (one random stream shared by all stages, as in `grow`); new
schedules never use it.

## Worked example: layered sheet from progenitors
`examples/layered_sheet.py` combines `seed_cells` in a `Sheet2D`, three cycles of `cell_cycle_clock` (C14) →
`temporal_competence` (C15) → `proliferate` (C2), `differentiate` (C7) into deep/mid/superficial excitatory and
superficial inhibitory types, `migrate` (C4) into a `LayerStackField`, laminar `grow_axons` (C8), wave-like
`refine_by_activity` (C11, STDP), and `prune` (C10):

```bash
python examples/layered_sheet.py --cpu --out example_out
```
